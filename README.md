# ☀️ Deye Solar & Dual Battery Real-Time Monitor

Повнофункціональна система онлайн-моніторингу сонячної електростанції **Deye (1-фазний гібридний інвертор + 2 акумулятори + сонячні панелі)** з сучасним веб-сайтом і **Telegram-ботом** реального часу.

Готово для швидкого розгортання на **Render.com**.

---

## 🚀 Що входить у проєкт

1. **🌐 Сучасний веб-дашборд (Real-Time):**
   - **Інтерактивна схема перетоку енергії (Tesla / Victron style):**
     - ☀️ Сонячні панелі (PV1 + PV2, потужність у Вт, напруга, струм, генерація за день).
     - 🔋 Система з **2 акумуляторів**: окремий моніторинг кожного блоку (SOC %, V, A, температура °C), статус заряду/розряду та прогнозований час роботи.
     - 🏠 Споживання будинку (миттєве навантаження у Вт, витрати за день).
     - 🌐 Міська мережа 220В: індикатор «Є світло» / «Блекаут», імпорт/експорт енергії.
   - **Динамічний графік (Chart.js):** криві генерації сонця, заряду батарей, навантаження та мережі.
   - **WebSockets:** оновлення даних щомиті без перезавантаження сторінки.
   - **Кнопка тесту аварії:** можливість змоделювати відключення світла в 1 клік.

2. **🤖 Розумний Telegram-бот (aiogram 3):**
   - Команди: `/status` (детальний поточний стан з емодзі та шкалами заряду), `/stats` (підсумки за день), `/notify` (керування підпискою).
   - Інлайн-кнопки швидкого оновлення та переходу на веб-сайт.
   - **Миттєві сповіщення (Push Alerts):**
     - 🚨 **Зникло світло 220В (Блекаут):** бот негайно пише про відключення мережі, вказує залишок заряду батарей та орієнтовний час автономної роботи.
     - ✅ **Світло повернулося:** повідомлення про відновлення напруги в мережі та початок заряду.
     - 🪫 **Попередження при розряді батарей (<20% та <10%).**
     - 🔋 **Повідомлення про 100% заряд батарей.**

3. **☁️ Хмарне підключення до Deye / Solarman:**
   - Працює напряму через офіційний **Solarman Open API v1.0** (хмара Deye Cloud / Solarman Smart).
   - Має вбудований симулятор з фізичною моделлю для миттєвого тестування без попередніх налаштувань.
   - Має захищений етап `POST /api/telemetry` для можливого локального шлюзу.

## 🛠️ Як отримати необхідні ключі

### 1. Telegram Bot Token
1. Відкрийте Telegram і знайдіть бота **[@BotFather](https://t.me/BotFather)**.
2. Напишіть `/newbot`, оберіть ім'я та юзернейм (наприклад, `MyDeyeSolarBot`).
3. Скопіюйте отриманий токен (формату `1234567890:ABCdef...`).
4. Щоб дізнатися свій особистий `chat_id` для отримання сповіщень, напишіть боту **[@userinfobot](https://t.me/userinfobot)** і збережіть числовий ID.

### 2. Ключі Solarman Open API (Deye Cloud)
1. Перейдіть на офіційний портал розробників: **[https://developer.solarmanpv.com](https://developer.solarmanpv.com)**.
2. Зареєструйтесь або увійдіть під тим самим акаунтом, що й у додатку **Solarman Smart / Deye Cloud**.
3. Створіть застосунок (App), щоб отримати:
   - `App ID`
   - `App Secret`
4. Серійний номер інвертора (`Inverter SN`) візьміть з наліпки на інверторі або з мобільного додатку (наприклад: `2406129841`).

## 🚀 Розгортання на Render.com (Покроково)

1. **Створіть репозиторій на GitHub:**
   ```bash
   cd /Users/pc/deye-solar-monitor
   git init
   git add .
   git commit -m "Initial commit of Deye Solar Monitor"
   # Створіть новий репозиторій на GitHub і запуште:
   git remote add origin https://github.com/ВАШ_ЛОГІН/deye-solar-monitor.git
   git branch -M main
   git push -u origin main
   ```

2. **Підключення до Render:**
   - Зайдіть на [render.com](https://render.com) та натисніть **New +** -> **Web Service**.
   - Оберіть ваш GitHub репозиторій.
   - Налаштування сервісу:
     - **Name:** `deye-solar-monitor`
     - **Region:** Frankfurt (EU)
     - **Branch:** `main`
     - **Runtime:** `Python 3`
     - **Build Command:** `pip install -r requirements.txt`
     - **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
     - **Plan:** Free (або Starter для 24/7 без зупинки)

3. **Додайте змінні середовища (Environment Variables) на Render:**
   - `TELEGRAM_BOT_TOKEN` = Ваш токен від @BotFather
   - `TELEGRAM_ADMIN_CHAT_IDS` = Ваш Telegram ID
   - `WEB_BASE_URL` = Посилання на ваш Render-додаток (наприклад: `https://deye-solar-monitor.onrender.com`)
   - `SOLARMAN_ENABLED` = `true`
   - `SOLARMAN_APP_ID` = Ваш App ID
   - `SOLARMAN_APP_SECRET` = Ваш App Secret
   - `SOLARMAN_EMAIL` = Ваш email у додатку Solarman / Deye
   - `SOLARMAN_PASSWORD` = Ваш пароль
   - `SOLARMAN_INVERTER_SN` = Серійний номер інвертора

4. Натисніть **Deploy Web Service**! За 1-2 хвилини ваш сайт і Telegram-бот працюватимуть онлайн.

## 💻 Локальний запуск для тестування (на вашому комп'ютері)

```bash
cd /Users/pc/deye-solar-monitor
# Активуйте віртуальне оточення
source venv/bin/activate

# Запустіть сервер
uvicorn app.main:app --reload --port 8000
```

Відкрийте в браузері: **[http://localhost:8000](http://localhost:8000)**.
Ви побачите дашборд, що оновлюється в реальному часі через WebSockets!
Натисніть кнопку **«Тест аварії 220В»** у верхньому правому кутку сайту, щоб побачити перехід в режим Off-grid та спрацювання сповіщень.
